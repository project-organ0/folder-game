# Folder Game — 퇴근 전 파일정리

윈도우 파일 탐색기처럼 보이는 드래그 숫자 퍼즐입니다. 폴더명 끝 숫자의 합이 10이 되도록 영역을 선택해 제한 시간 안에 파일을 정리하세요.

## MVP 기능

- 탐색기 스타일의 게임 화면
- 드래그 영역 선택 및 합계 판정
- 3단계 난이도
- 점수, 정리한 폴더 수, 확보 용량 표시
- `ESC` 상사 모드 및 타이머 일시정지
- 데스크톱·모바일 반응형 레이아웃

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 생성합니다.
